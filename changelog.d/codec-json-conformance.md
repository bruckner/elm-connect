- A `double` field written as a JSON number past a double's range (such
  as `1e999`, which JavaScript's JSON parser reads as an infinity) fails
  to decode, and a `float` field (and `Proto.WellKnown.floatValue`)
  fails on a value whose magnitude is past the largest `float`,
  3.4028234663852886e38. Both were read as given
  before; the strings `"Infinity"`, `"-Infinity"` and `"NaN"` still
  decode. Code generated by this release decodes `float` fields with the
  new `Proto.Json.float32`.
- `Proto.Timestamp.fromString`, and so every `Timestamp` field, refuses
  a lowercase `t` or `z` (`1970-01-01t00:00:00z`): RFC 3339 allows
  them, proto3 JSON does not. They were accepted before.
- An `Any` whose `"@type"` is not a type URL (empty, without a `/`, or
  with nothing after the last `/`) fails to decode; it was read as an
  `Any` of that text before. A well-formed URL of a type the client does
  not know still decodes.
- A `FieldMask` whose JSON holds an `_` (`"display_name"`) fails to
  decode: proto3 JSON writes its paths in lowerCamelCase
  (`"displayName"`). It was read as the path `display_name` before.
- The generator maps the enum `google.protobuf.NullValue`, which it
  refused with `types::unsupported_well_known` before: a field of it is
  `()`, decoded from `null`, `"NULL_VALUE"` or `0` and written `null`
  (a singular field, `optional` too, has no presence and is left out),
  and a oneof member of it has no argument and is set by `null`. The
  runtime adds `Proto.Json.nullValue`, `encodeNullValue`,
  `nullValueMember`, `nullValueMemberEither` and
  `Proto.WellKnown.nullValue`.
- A `string` field, a `StringValue` and a `string` map key holding a
  UTF-16 surrogate without its pair (`"\udc00"`, which JavaScript's JSON
  parser reads into the string as it is) fail to decode; such a string
  is not Unicode text. Code generated by this release decodes them with
  the new `Proto.Json.string` and `Proto.Json.stringDict`, which check
  each string once: decoding a note in the benchmark takes about 5 %
  longer, a page of 1,000 notes about 1 %.
