- Reading protobuf binary is faster: by about a quarter to a third for
  a single message, a list of 300 and nested or 16-field messages in
  the package's benchmark, a fifth for map-heavy messages and for a
  1 KB answer over Connect's proto codec. Unpacking an `Any` takes 18
  to 24 % less time, and writing one as JSON 16 % less.
- Code generated by this release sets a field in a binary merge step
  by writing the record out whole, for a message of up to 64 fields,
  where it used a record update; such messages decode five to seven
  times faster field by field, and the generated module is larger (a
  64-field message's merge is about 0.8 KB gzipped more). Generated
  code from earlier releases works as before.
