# Cases of the protobuf conformance suite (protocolbuffers/protobuf
# conformance/, runner v32.0-rc2 from bufbuild/protobuf-conformance) the
# testee fails, for conformance_test_runner --failure_list. Proto3 only:
# proto2 and editions messages, JSPB and text format are answered skipped.
# Each group is classified: ours (the runtime or generator could do it),
# spec choice (a documented elm-connect choice the suite disagrees with),
# unsupported (a feature elm-connect does not have).

Required.Proto3.ProtobufInput.UnknownOrdering.ProtobufOutput

# ours: an Any holding a message's proto3 JSON (not a well-known type's) is
