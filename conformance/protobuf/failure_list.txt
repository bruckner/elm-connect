# The cases of the protobuf conformance suite (protocolbuffers/protobuf
# conformance/, runner v32.0-rc2 from bufbuild/protobuf-conformance) the
# testee fails, for conformance_test_runner --failure_list. The testee runs
# proto3 JSON in and JSON out only; everything else is answered skipped
# (README.md). The runner fails a run when a listed case passes, so the list
# cannot go stale.
#
# Each group says why, and is either a design choice (documented behaviour
# the suite disagrees with) or a fix candidate (behaviour the runtime or the
# generator could change).

# Design choice: a Timestamp is a Time.Posix, which holds milliseconds, so
# digits past the third are dropped.
Required.Proto3.JsonInput.TimestampLittleAfterEpochlValue.JsonOutput
Required.Proto3.JsonInput.TimestampLittleBeforeEpochValue.JsonOutput
Required.Proto3.JsonInput.TimestampMaxValue.JsonOutput
Required.Proto3.JsonInput.TimestampNanoAfterEpochlValue.JsonOutput
Required.Proto3.JsonInput.TimestampNanoBeforeEpochValue.JsonOutput
Required.Proto3.JsonInput.TimestampRepeatedValue.JsonOutput
Recommended.Proto3.JsonInput.TimestampHas6FractionalDigits.Validator
Recommended.Proto3.JsonInput.TimestampHas9FractionalDigits.Validator

# Design choice: a 64-bit integer written as a JSON number past 2^53 is
# rounded by JavaScript's JSON parser before the decoder sees it, so it is
# read with the wrong digits or out of range (Proto.Json.int64).
Required.Proto3.JsonInput.Int64FieldMaxValueNotQuoted.JsonOutput
Required.Proto3.JsonInput.Int64FieldMinValueNotQuoted.JsonOutput
Required.Proto3.JsonInput.Uint64FieldMaxValueNotQuoted.JsonOutput

# Design choice: an enum number the client does not know reads as the zero
# value, which is not written back (the enum_unknown option).
Required.Proto3.JsonInput.EnumFieldUnknownValue.Validator

# Design choice: a key written twice in one object reads as its last value.
# JavaScript's JSON parser keeps only the last, so only the response text
# shows the first, and checking it is a scan of every body that costs more
# than decoding it (docs/design.md, section 3.4).
Recommended.Proto3.JsonInput.FieldNameDuplicate
