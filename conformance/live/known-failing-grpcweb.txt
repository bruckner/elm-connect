# Test cases of the Connect conformance suite (conformance-grpcweb.yaml) that
# elm-connect's runtime is known to fail over gRPC-Web, whichever way a call
# is sent; known-failing-grpcweb-halves.txt adds those only the pure halves
# fail, and known-failing-send.txt those Rpc.sendTraced fails. Format as in
# known-failing.txt.

# A unary answer with status 0 and no message, or with two messages: the
# suite wants `unimplemented`; the runtime reads a malformed answer as a
# BadResponse, whose code is `internal`, as it does over Connect.

gRPC-Web Unexpected Responses/**/unary/multiple-responses

# A 200 whose content type is not gRPC-Web's and whose body holds no status:
