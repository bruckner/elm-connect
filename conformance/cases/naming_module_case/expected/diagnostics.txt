naming::module_collision

  × The generated modules `Shop.API` and `Shop.Api` differ only in case, so
  │ they are written to the same file on macOS and Windows.
   ╭─[upper.proto:4:1]
 3 │ // `Shop.Api` and `Shop.API` are one file where case is ignored.
 4 │ package shop.API;
   · ────────┬────────
   ·         ╰── package `shop.API` becomes `Shop.API`
 5 │
   ╰────
  help: Each module is written to a file named for it (`Notes.V1` to `Notes/
        V1.elm`), and the default file systems of macOS and Windows ignore
        case, so one of these would overwrite the other. Rename the service or
        the package, or rename one with `rename=shop.api:<Elm name>`.

Advice:
  ☞ and in `lower.proto`:
   ╭─[lower.proto:3:1]
 2 │
 3 │ package shop.api;
   · ────────┬────────
   ·         ╰── and package `shop.api` becomes `Shop.Api`
 4 │
   ╰────
