  help: With `unbound_methods=error`, every method needs a rule. Without one,
        a call over transcoding takes the implicit route, `POST /
        <package>.<Service>/<Method>` with the request as its body, which
        grpc-gateway serves with `generate_unbound_methods`, Envoy's
        transcoder with `auto_mapping`, and Vanguard always. Add a rule to the
        method, or set `unbound_methods=implicit` (the default) if the server
        serves that route.
