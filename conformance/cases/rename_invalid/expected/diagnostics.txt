options::invalid_rename

  × The rename of `notes.v1` gives `notes.api`, which a package cannot be
  │ named.
   ╭─[notes.proto:7:1]
 6 │
 7 │ package notes.v1;
   · ────────┬────────
   ·         ╰── a package here
 8 │
   ╰────
  help: `notes.v1` is a package, which becomes an Elm module name, and a
        rename's name is used as it is, so it must be dot-separated segments,
        each an ASCII uppercase letter followed by letters, digits or
        underscores (`Notes.Api`).

options::unknown_rename

  × The rename of `notes.v1.Missing` names nothing elm-connect generates.
  help: A rename names a package, service, method, message, enum, field, oneof
        or enum value of a generated package by its proto full name, as the
        proto declares it (`notes.v1.Note.page_count`, not `pageCount`):
        nested names dotted (`notes.v1.Note.Revision`), an enum value under
        its enum (`notes.v1.Visibility.VISIBILITY_PUBLIC`).
