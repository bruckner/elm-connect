  help: elm-connect generates from `syntax = "proto3";` files and from
        `edition = "2023";` and `edition = "2024";` files whose features have
        an Elm form (explicit or implicit presence, `LEGACY_REQUIRED`, open
        and closed enums, packed repeated fields, checked UTF-8, the proto3
        JSON mapping). Declare `edition = "2024";` instead, if the file uses
        nothing a later edition added.
