types::map_key

  × The map field `by_value` of `flags.v1.Flags` has `bool` keys, which elm-
  │ connect cannot put in an Elm `Dict`.
   ╭─[flags.proto:7:3]
 6 │ message Flags {
 7 │   map<bool, string> by_value = 1;
   ·   ────────┬────────
   ·           ╰── a `bool` key
 8 │ }
   ╰────
  help: A map becomes a `Dict`, whose keys must be `comparable`, and Elm's
        `Bool` is not. Use `string` keys ("true" and "false", as proto3 JSON
        writes them), or two fields.
